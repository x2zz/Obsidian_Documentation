## Usage

Create a Glass Panel by calling `AddGlassPanel` on a Groupbox.

```lua
Groupbox:AddGlassPanel({
    Title       = "Status",
    Description = "Connected to server.",
    Icon        = "wifi",
    Badge       = "LIVE",
})
```

## Methods

#### SetTitle
Updates the title text.

```lua
Panel:SetTitle("Disconnected")
```

#### SetDescription
Updates the description text.

```lua
Panel:SetDescription("Lost connection to server.")
```

#### SetVisible
Shows or hides the panel.

```lua
Panel:SetVisible(false)
```

## Examples

### Basic info card

```lua
Left:AddGlassPanel({
    Title       = "Player",
    Description = "Naellx  •  Rank 42",
    Icon        = "user",
})
```

### Status badge

```lua
Left:AddGlassPanel({
    Title       = "Server",
    Description = "asia-southeast1  •  24ms",
    Icon        = "server",
    Badge       = "ONLINE",
    AccentColor = Color3.fromRGB(80, 200, 120),
})
```

### No gradient

```lua
Left:AddGlassPanel({
    Title    = "Warning",
    Icon     = "triangle-alert",
    Gradient = false,
    Height   = 50,
})
```
