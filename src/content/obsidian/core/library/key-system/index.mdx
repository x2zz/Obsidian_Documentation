## Overview

Obsidian Modified includes four key system functions that display an [Arqel UI](https://github.com/Cobruhehe/expert-octo-doodle) key entry screen before your main script runs.

Arqel is loaded at runtime from GitHub. If `getgenv().Arqel` is already present (e.g. loaded by another script), it reuses that instance.

All four functions **block execution** until the user enters a valid key or closes the window. If the key check fails or the user closes the screen, the function returns `nil` — check for this before continuing.

```lua
local key = Library:CreateKeySystem({ ... })
if not key then return end  -- user closed or key was invalid

-- main script below
local Window = Library:CreateWindow({ ... })
```

## CreateKeySystem

Authenticates via the **[Junkie](https://jnkie.com)** SDK.

```lua
local key = Library:CreateKeySystem({
    Service    = "My Hub",
    Identifier = "12345",
    Provider   = "Mixed",
    Title      = "My Hub",
    Subtitle   = "Enter your key below",
    GetKey     = "https://linkvertise.com/...",
    Discord    = "https://discord.gg/...",
    Remember   = true,
    AutoLoad   = true,
    Blur       = true,
    SuccessCallback = function(k) print("Key:", k) end,
    FailCallback    = function(e) warn("Error:", e) end,
})
if not key then return end
```

## CreateArqelKeySystem

Uses a custom **`OnVerify`** callback — bring your own validation logic.

```lua
local key = Library:CreateArqelKeySystem({
    Title   = "My Hub",
    Subtitle = "Enter your key below",
    GetKey  = "https://...",
    Discord = "https://discord.gg/...",
    OnVerify = function(inputKey)
        -- Call your own backend here
        if inputKey == "MY-SECRET-KEY" then
            return { valid = true }
        end
        return { valid = false, error = "KEY_INVALID", message = "That key is not valid." }
    end,
    SuccessCallback = function(k) print("Key:", k) end,
    FailCallback    = function(e) warn("Error:", e) end,
})
if not key then return end
```
